# เครื่องมือตัดชื่อคู่ความแบบออฟไลน์ 0.7.8

เปิด `notice-pay-party-cleaner-offline.html` ใน Chrome หรือ Edge บนเครื่องในศาล ปิดอินเทอร์เน็ตได้ ไม่มีการเรียก API หรือบันทึกข้อมูลลงฐาน/พื้นที่เก็บของเบราว์เซอร์ ตัวอ่าน ZIP และ `import-formats.js` ฝังใน HTML แล้ว

## กฎข้อมูล 4 จุด

1. ผู้รับ: ใช้ R1-SHA256 จาก `NoticeImportFormat.recipient` ชุดเดียวกับระบบค่าหมายทุกตัวอักษร ผูกกับเลขคดีตามกฎเดิม ไม่ใช้ฐานะหรือชื่อบทบาทแทนรหัส หากมีฐานะให้คงคอลัมน์ฐานะแยกต่างหาก ไม่สร้างฐานะเอง
2. ผู้วางเงิน: เว้นว่าง รวมถึงไม่ใส่ข้อความมีผู้วางเงิน ชื่อโจทก์และจำเลยเว้นว่างในคอลัมน์เดิม
3. เลขคดี: คงค่าต้นฉบับ รวมเลขไทย ช่องว่าง และบรรทัดในเซลล์ ใช้กฎมาตรฐานเฉพาะภายในฟังก์ชันสร้างรหัส ไม่เขียนทับเลขคดีในไฟล์
4. รายงาน: คงหัวรายงาน แถวจ่ายเงินให้เจ้าหน้าที่ แถวยอดท้าย สูตร ยอดตัวเลข รูปแบบเซลล์ และการรวมเซลล์ ไม่ตัดแถวหรือเลื่อนตำแหน่งคอลัมน์

รองรับ `.xlsx` ที่มีหัวเลขคดีและผู้รับ/คู่ความ/ผู้วางเงิน รวมตารางซ้ำหลายชุดและหลายชีต หัวตารางต้องตรงรายการที่รองรับ หากเป็น `.xls` ให้เปิดใน Excel แล้วบันทึกสำเนา `.xlsx` ก่อน ใช้ไฟล์ต้นฉบับจริงในเครื่องในศาล ไม่อัปโหลดชื่อคู่ความมาทดสอบบนระบบสาธารณะ

เครื่องมือแปลง shared strings เป็น inline strings และลบตารางข้อความเดิมที่อาจเก็บชื่อที่ไม่ใช้งานแล้ว หยุดก่อนส่งออกหากไม่มีเลขคดี พบชื่อเดิมในส่วนอื่น มีสูตรในช่องชื่อ หรือมีความคิดเห็น/ภาพ/วัตถุฝัง/ลิงก์ภายนอก/ส่วนเสริมที่ยังตรวจไม่ได้ ห้ามตีความข้อความสำเร็จว่าเป็นการรับรองชื่ออิสระทุกตำแหน่งที่ไม่อยู่ในหัวคอลัมน์ที่รู้จัก

ก่อนนำเข้าจริง ตรวจจำนวนฉบับ ยอดรวม รายผู้ส่ง หัวและยอดท้าย เทียบต้นฉบับ แล้วทดลอง preview ไฟล์เดิมซ้ำเพื่อยืนยันว่าไม่เพิ่มรายการ ไม่ใช้ผู้วางเงินเป็นคีย์ เพราะคอลัมน์นี้เว้นว่างแล้ว รหัส R1 เป็นรหัสเชื่อมโยง ยังต้องใช้สิทธิ์เข้าถึงเดิม

## สำรองที่มีชื่อเดิมบน Google

สถานะของคู่มือนี้: ยังไม่ได้ยืนยันว่าโอนไฟล์สำรองลงเครื่องในศาล และยังไม่ได้ลบถาวร ห้ามถือว่าการดาวน์โหลดลงเครื่องมือออนไลน์หรือเบราว์เซอร์บนคลาวด์เป็นการเก็บในศาลแล้ว

ให้เจ้าของบัญชีดาวน์โหลดไฟล์สำรองก่อนลบชื่อจาก Google Sheets เป็น `.xlsx` ลงพื้นที่ภายในที่ศาลกำหนด เปิดไฟล์นั้นจากเครื่องในศาล ตรวจครบทุกชีต จำนวนรายการ ยอดรายผู้ส่ง ยอดรวม รอบยืนยัน และการเชื่อมรายการ เทียบกับบันทึกตรวจสอบเดิม ใช้พื้นที่ภายในที่กำหนดสิทธิ์และไม่ซิงก์กลับ Google

หลังเจ้าของยืนยันว่าเปิดสำเนาในศาลและตรวจยอดครบ จึงย้ายเฉพาะไฟล์สำรองที่ระบุไปถังขยะ จากนั้นตรวจชื่อ/รหัสไฟล์อีกครั้งและยืนยันลบเฉพาะไฟล์นั้นอย่างถาวร ไม่ล้างถังขยะทั้งบัญชี และไม่ลบฐานใช้งานจริง การลบถาวรต้องยืนยัน ณ ขั้นตอนนั้น

การลบไฟล์จาก Google Drive ไม่ใช่หลักฐานว่าลบสำเนาที่บุคคลอื่นดาวน์โหลดหรือข้อมูลที่อาจอยู่ในระบบเก็บรักษาขององค์กรแล้ว ให้ผู้ดูแลใช้ขอบเขตการจัดเก็บของศาลตามจริง

## การสร้างและตรวจโค้ด

รัน `node tools/party-cleaner/build.js` หลังแก้ shared formatter เสมอ เพื่อให้ HTML ฝังกฎจากไฟล์จริง ทดสอบ `test/party-cleaner.test.js` ด้วยข้อมูลจำลอง ทดสอบการแปลงซ้ำและตรวจชื่อใน ZIP ก่อนแจกจ่าย

JSZip 3.10.1 ใช้ใบอนุญาต MIT/GPLv3 (รายละเอียดอยู่ต้นไฟล์ jszip.min.js) เครื่องมือนี้ไม่ใช้ฐานข้อมูลรหัสบุคคล

## ข้อความอิสระ รุ่น 0.7.8

- ใช้ nameMatches/redactNames จาก import-formats.js ไฟล์เดียวกับหลังบ้าน สแกนทุกเซลล์ทุกชีต รวมชีตซ่อน หัวรายงานและท้ายรายงาน
- ช่องผลการส่งหมายและหมายเหตุแทนคำนำหน้าชื่อกับคำถัดไปไม่เกินสองคำด้วย [ตัดชื่อ] และสแกนซ้ำ หากยังพบในตำแหน่งอื่น หยุดส่งออก แจ้งลำดับชีต แถวและคอลัมน์โดยไม่พิมพ์ชื่อ
- ยกเว้นผู้ส่งหมาย/ผู้ปฏิบัติ/เจ้าของหมาย แถวจ่ายเงินให้ เลขคดีที่เป็นข้อมูลคดี รหัส R1 ชื่อถนน/ซอย/พื้นที่ตามคำนำหน้าที่ระบุ และคำกฎหมายที่กำหนด ไม่ยกเว้นคอลัมน์เลขคดีทั้งคอลัมน์จนทำให้ชื่อบนท้ายรายงานหลุด
- คงยอด เซลล์ตัวเลข สูตรและโครงรายงาน ไม่แก้สูตรที่พบชื่อ แต่หยุดให้ตรวจแทน สถิติแสดง ตัดชื่อในข้อความอื่น … จุด
- หลังบ้านปฏิเสธคำขอนำเข้าที่ตรวจพบชื่อในข้อความ โดยตอบ BAD_REQUEST ก่อน journal/บันทึก รวมคอลัมน์ส่วนเกินที่ส่งมา ผู้รับและผู้วางเงินยังผ่านกฎ R1/เว้นว่างก่อนตรวจซ้ำ
- เป็นการตรวจตามคำนำหน้าและขอบเขตคำที่กำหนด ไม่ใช่การยืนยันว่าไม่มีชื่อที่ไร้คำนำหน้า สะกดแปลก หรือเกินสองคำ จึงยังต้องตรวจไฟล์และจำกัดสิทธิ์เดิม

ฟังก์ชัน auditFreeText078 ตรวจ NOTICES.result และ IMPORT_REVIEW.raw_json แบบอ่านอย่างเดียว ส่งออกเฉพาะจำนวนกับ hash ฟังก์ชัน preview/applyFreeTextCleanup078 ใช้สำรองส่วนตัวที่ hash ตรง ล็อกระหว่างเขียน ตรวจค่าทุกตารางนอก result/result_hash/raw_json และตรวจผลคำนวณ/ยอดก่อนหลัง พร้อมคืนค่าเมื่อเขียนสะดุด ไม่มี API route สำหรับฟังก์ชันเหล่านี้
