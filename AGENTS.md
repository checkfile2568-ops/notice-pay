This is NOT proof of live correctness and NOT permission to roll back the whole application. Preserve newer approved capabilities. Main at a2379722 is an audit snapshot, NOT a certified release. ## Non-negotiable
- No deletion, reset, reclassification, silent recalculation of confirmed/paid rounds, or financial formula/rounding changes unless explicitly authorized. Preserve the existing 60/40 method and historical results. Never fabricate a missing API or silently fall back to a different workflow.
- Preserve input formats, mapped columns, identifier semantics, date/fiscal-year rules, existing UI/workflows, permissions, API contracts, database columns, and configuration/endpoint values outside the requested scope.
- Single and multi-file import must use the same proven parsing/validation/persistence semantics. Respect the dependency order 50 → 42 → 18 → 30; Form25 remains separately supported. Exact duplicates proven by existing identity rules are not new records. Distinct notices sharing case numbers are not duplicates. Ambiguous items require review; never discard silently. Allow changed free-notice amounts only after explicit old/new confirmation and protect confirmed/paid rounds. Do not bypass privacy or validation checks.
- Preserve R1 anonymization; never commit real Excel, case data, secrets, PINs, database IDs copied from private sources, credentials or live response payloads into this public repository. Locate previously supplied files in authorized private storage before asking again; use anonymized copies and a private fixture manifest, expected output and checksums. Synthetic data supplements but never replaces verified historical regression data.
- Never deploy an untested patch to main. Use a candidate branch, review diffs and configuration invariants, run tools/check-release.js and regression tests against the actual candidate frontend plus matching GAS. Compare candidate results against historical verified expected results and test on isolated database copies. Verify counts, money, permissions, errors, duplicates, expiry, retry, interruption, cache and readback. Repeat tests after every fix; do not mark complete without evidence.
- The public Pages build only proves static deployment, not business correctness. Never infer live backend version or state from repository source. Record current deployed version using authorized read-only checks and confirm one release manifest binds code, configuration, fixtures, tests and deployment. No production financial writes as a test. Stop and report precise blockers if required evidence is unavailable.
